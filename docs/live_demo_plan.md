# Live Demo Plan

## Main idea
A notebook pipeline becomes more professional when it is run as a repeatable Databricks Job instead of being launched manually step by step.

## Flow
1. Show repo structure
2. Clone into Databricks
3. Review the pipeline notebooks
4. Create a Databricks job
5. Add bronze, silver, gold, and quality tasks
6. Run the job
7. Monitor the run
8. Add a schedule

## Logical focus
- why jobs matter
- why dependencies matter
- why monitoring matters
- how orchestration improves pipeline operations
